# MTEL-OSR-001 candidate

This directory contains the candidate executable surface for the Observable-State Reconstruction Protocol.

Current state: **CANDIDATE / NOT RELEASED**.

The protocol is intentionally meta-level: it tests whether selected existing governance relations can be reconstructed from bounded observable state across isolated heterogeneous hosts. It does not introduce a new governance primitive.

Candidate qualification here is limited to instrument structure, deterministic evaluator behavior, and false-pass resistance. Public release remains a separate review and authorization step.
